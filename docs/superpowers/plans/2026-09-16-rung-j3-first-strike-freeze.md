# Rung J3 — First Strike and Freeze: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** First Strike splits a blocked battle's damage into two batches with a pass-only priority window between them and defers its triggers; Freeze is a status that skips one Active Phase; Dragoon 1-147C, Shiva 1-038R and Summoner 1-040C are in both decks so both rules are played and tested on real cards.

**Architecture:** the Attack Phase gains a `firstStrike` window step between `blocked` and `damage`; `resolveDamage` is split into "compute hits" and "land a batch" so it can run twice; held damage occurrences live on `AttackState`. Freeze is one boolean on `FieldCard`, one effect kind, two events, one branch in `startTurn`. Cards are data plus one AST. The AI needs no code. The browser gets a badge, two log lines and a step label.

**Tech Stack:** TypeScript, vitest, the existing engine/cards/web packages. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-09-16-rung-j3-first-strike-freeze.md`
